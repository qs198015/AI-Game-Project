# 骗子宠物馆：黑月酒桌

中文版单机心理欺骗卡牌 Web 游戏。风格是 **暗黑奇幻酒馆 + 拟人宠物 + 夸张表情喜剧**，无需安装依赖即可游玩。

## 当前可玩内容

- 完整第一章《黑猫入局》：8 局、约 5 分钟，可通关、失败结算并重新挑战。
- 🐱 夜影对阵 🐶 铁牙、🦊 红尾、🐰 雪球；三位 AI 同桌轮流出牌，各有独立的骗人率、怀疑倾向、动作线索和台词。
- 4 种牌：黄金骨头、臭鱼、贵族奶酪、可冒充任意牌的幻影牌；每次可盖 1–3 张并选择四种演技。
- 3 件一次性诡计道具：臭袜子炸弹、魔术帽、会说话的鸡腿。
- 新手教学、章节进度、酒桌记录、夸张胜负反馈、卡牌翻面与桌面动效。
- 响应式手机 / 平板操作，支持减少动态效果偏好；Web Audio 音效接口可切换且会自动静默降级。
- 完全单机：无账号、联网、商城或排行榜。

## 运行方式

直接用浏览器打开 `index.html`，或启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 玩法

1. 选择 1–3 张牌，宣称它们属于同一种牌，并选一种表演方式。
2. AI 可能相信或质疑；说谎被抓、质疑真话的一方会失去生命。
3. 对手盖牌时，根据其性格、动作和台词选择相信或抓现行。提示有用但绝非百分百准确。
4. 在 8 局内让三位对手全部出局即可完成第一章。

## 第三阶段美术与世界观

黑月酒馆坐落在“旧钟街”尽头，只在没有月亮的夜晚营业。这里的筹码不是钱，而是客人是否还敢相信自己的判断。酒保夜影掌控牌桌；狐狸红尾用挑衅掩盖破绽；乌鸦鸦策把每次犹豫当成数据；贵族雪球则把危险藏在可爱礼仪下面。

- `assets/portraits/` 提供四位核心角色的原创 SVG 头像资源，并保留 `portrait` 字段作为未来替换正式立绘的接口。
- 每位核心角色拥有独立主色、冷静／思考／挑衅／受伤／胜利表情标记，以及角色专属胜负台词。
- 场景增加黑月窗景、瓶架、木牌、酒杯、钥匙与啤酒等酒馆陈设；桌面继续使用轻量 CSS 绘制，避免影响移动端性能。
- 卡牌增加统一牌厂标记、双层边框与稀有卡虹彩辉光；头像和卡牌资源均为本地资源，不依赖网络。

## 开场动画

页面载入后会播放约 19 秒的轻量电影式开场：黑屏月光、黑月 LOGO、旧钟街酒馆、推门与烛光转场，然后依次介绍夜影、红尾、鸦策和雪球。右上角可随时跳过；开启“精简动态”后会自动使用极短转场。

开场仅通过 HTML、CSS Animation 和 JavaScript 时间线实现，不加载视频或第三方运行库。粒子、雾气、镜头缩放和转场主要使用 `transform` 与 `opacity`；神秘低频氛围音使用 Web Audio 接口，并遵守浏览器必须由用户交互启动声音的限制。主菜单现提供“开始游戏 / 角色介绍 / 卡牌收藏 / 设置”四个明确入口。

## E 阶段：角色动画与心理战表现

- 四张核心 SVG 头像加入低成本眨眼动画；运行时以 `idle / thinking / smug / hurt / win` 状态驱动观察、靠近、挑衅、慌张、敲桌和冷静胜利动作。
- 选牌与出牌会产生高亮、角色视线变化及卡牌飞向桌心的动画；揭晓时保留翻牌，并加入桌面震动、放射粒子和大字结果反馈。
- HUD 新增当前回合、对手状态、动态怀疑程度、紧张红光、连胜火焰和动画事件日志。怀疑条只展示 AI 对玩家本次表演的警觉度，不泄露 AI 手牌真假。
- “⏩”按钮可跳过当前酒局剩余等待动画；精简动态模式会关闭飞牌及循环动画。所有临时粒子在播放后自动移除，不保留 Canvas 循环或后台计时器。

## 试玩版发布与验证

### 最快试玩

下载仓库后直接双击 `index.html`。角色、卡牌和样式全部来自本地文件；在 `file://` 模式下游戏、设置与本地存档仍然可用，只有离线 Service Worker 不会注册。

推荐通过静态服务器试玩，以获得和线上版本一致的缓存行为：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

首次进入可观看或跳过开场，然后按“开始游戏 → 选择角色 → 带他入局”开始。每局选择卡牌、宣称牌型和演技；对手出牌时选择相信或抓现行。八局内击败三位对手即通关，结算页可重新选角或返回主菜单。设置、成就与生涯统计会自动保存在当前浏览器。

### 发布检查

项目不需要安装生产依赖。Node.js 18+ 可运行随仓库提供的检查：

```bash
npm test          # 完整 UI 流程与资源冒烟测试
npm run verify    # 发布文件、引用和核心体积预算
```

### GitHub Pages

仓库包含 `.github/workflows/pages.yml`。在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**；推送到 `main`、`master` 或当前 `work` 分支后，工作流会先执行测试，再发布静态试玩版。`sw.js` 会在 HTTP/HTTPS 环境缓存约 84 KiB 的核心资源，更新版本时通过缓存名称进行失效；直接打开 HTML 时不会尝试注册 Service Worker。

### 浏览器建议

推荐最新版 Safari、Chrome、Edge 或 Firefox。界面适配 iPhone/iPad 安全区域；不支持 `backdrop-filter`、`color-mix()` 或原生 `<dialog>` 的浏览器会使用纯色边框与 `open` 属性回退。系统“减少动态效果”、游戏内“精简动态”和“减少数据”偏好均有对应降级。
