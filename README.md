# 骗子宠物馆：黑月酒桌

这是一个中文单机欺骗 / 心理博弈网页游戏原型，方向类似“骗子酒馆”类型，但角色全部是拟人化宠物，风格为：

**暗黑奇幻酒馆 + 夸张搞笑 + 宠物赌徒 + 卡牌心理战**

## 目前可玩内容

- 玩家角色：🐱 夜影（黑猫）
- AI 对手：🐶 铁牙（黑犬）
- 生命值系统
- 手牌系统
- 宣称牌型
- 说真话 / 说谎
- AI 是否质疑玩家
- 玩家判断 AI：相信 / 怀疑
- 夜影技能「猫爪偷牌」
- 胜负结算
- 中文 UI
- 手机浏览器响应式布局

## 运行方式

最简单：直接用浏览器打开 `index.html`。

如果本地浏览器阻止某些资源，可在目录中启动静态服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 下一阶段目标

优先级从高到低：

1. 加入 🦊 红尾 和 🐰 雪球，完成 4 宠物单机桌局。
2. 把当前 emoji 占位角色替换为正式立绘 / 精致视觉资源。
3. 做真正的卡牌翻转、出牌滑动、表情和酒馆动态效果。
4. 加入搞笑道具：臭袜子炸弹、魔术帽、会说话的鸡腿。
5. 改进 AI：记忆玩家骗人习惯、不同角色性格差异。
6. 做第一章剧情《黑猫入局》。
7. 继续保持单机，不做联机，直到核心玩法经过试玩验证。

## 重要产品约束

- 游戏必须是中文版。
- 暂时不要做联机。
- 不要优先做商城、海报、营销页。
- 先把游戏本身做精致、好玩、完整。
- 核心要有夸张搞笑感，不要做成纯严肃暗黑。
- 角色必须包含猫和狗，后续核心阵容为黑猫、黑犬、狐狸、白兔。
- 参考视觉：暗黑奇幻酒馆、电影级灯光、拟人宠物、华丽卡牌桌。
